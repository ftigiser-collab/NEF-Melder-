# NEF-Melder

Einsatzcodes Rettungsdienst RLP (2023_v1) antippen und passende Differenzialdiagnosen sowie Kapitel aus „Präklinik kompakt“ bekommen.

- **Melder:** Codes wie auf dem Funkmelder eintippen; die Kind-Codes 907–910 setzen die Altersgruppe automatisch.
- **Organsystem:** Leitsymptome mit Differenzialdiagnosen je Altersgruppe (Erwachsen, > 12 J, 7–12 J, 1–6 J, < 1 J).
- **Kapitel:** das ganze Taschenbuch mit Volltextsuche.

Single-file PWA (React 18 + Babel Standalone über CDN), offline über `sw.js`. Beim Update `VERSION` in `sw.js` hochzählen.

Persönliche Gedächtnisstütze, nicht zur Weitergabe. Maßgeblich bleiben die SOPs, der ÄLRD und die Fachinformationen.
